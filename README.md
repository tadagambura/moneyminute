# MoneyMinute

> **Merged into [StackUp](https://github.com/tadagambura/stackup).**

The daily one-minute money lesson (streaks, XP, levels, lessons checked against GOV.UK,
MoneyHelper, HMRC and the FCA, inspired by the ideas in The Psychology of Money) now lives
inside StackUp: save money and learn money, one minute a day.

This repo is kept for history and is no longer developed.
